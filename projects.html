    문화콘텐츠 제작 기술 혁신을 위한 생성 AI 모델 성능 향상

    가상융합기술연구원 R&D 기획발굴 과제 · 2025 –

    문화콘텐츠 산업의 제작 공정에 쓰이는 생성 모델의 품질과 제어 가능성을 높이는 과제. 이미지·영상 생성 모델의 조건 제어와 편집 방법을 다룹니다.

  • GENERATIVE AI진행 중

    콘텐츠 제작 공정을 위한 생성 AI 기술 개발

    산학공동기술개발 · 주관 동서대학교, 참여 더만타스토리 · 2026 –

    기업 수요조사를 바탕으로 콘텐츠 제작 공정에 생성 AI를 적용하는 3개년 연구개발. 이미지·영상 생성 모델의 제작 현장 적용과 후속 정부지원사업 연계를 목표로 합니다.

  • LLM · AGENTS진행 중

    로컬 LLM 멀티 에이전트 시스템

    연구실 자체 과제 · 2026 –

    클라우드에 의존하지 않는 언어모델 에이전트. 오케스트레이터·연구·개발·비서 역할의 에이전트 4종을 로컬 모델로 구동하고 메신저로 연결합니다. 오픈웨이트 모델 선정과 서빙 최적화가 핵심입니다.

  • GENERATIVE AI진행 중

    ComfyUI 콘텐츠 생성 파이프라인

    연구실 자체 과제 · 2026 –

    텍스트-투-이미지·영상·음성 생성과 립싱크 영상 제작을 하나의 워크플로로 묶습니다. 원격 GPU 서버에서 헤드리스로 돌고, 긴 오디오 분할·병합과 한국어 음성 합성을 포함합니다.

  • INFRASTRUCTURE완료

    연구실 AI 서버 구축

    연구실 자체 과제 · 2026

    GPU 서버에 오픈웨이트 언어모델과 생성 모델 서빙 환경을 구축했습니다. vLLM·Ollama로 코딩 에이전트를 로컬 모델에 연결하고, 연구실 구성원이 원격으로 접속합니다.
